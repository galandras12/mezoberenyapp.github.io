Mezőberény App — tartalom előállítása kézi beillesztéshez

Ez az oldal semmit nem ment el magától. Az eszköz csak JSON szöveget állít elő — a data/…json fájlba neked kell beilleszteni (GitHub → a fájl → Edit → beillesztés → Commit changes).
A lap nincs linkelve a főoldalról és a keresők elől is el van rejtve, de a GitHub Pages minden fájlt nyilvánosan szolgál ki: aki ismeri a címet, meg tudja nyitni. Jelszót ne írj ide.
